# 5MinutesAPI - Official n8n Node

![5MinutesAPI](https://5minutesapi.com/logo.png)

The official [5MinutesAPI](https://5minutesapi.com) integration for n8n. Automate your WhatsApp Business messaging, send OTPs, and build 2-Way interactive flows directly through the Official Meta Cloud API—with **Zero Markup**. 

## 🚀 Why Use 5MinutesAPI?
- **Zero Markup Pricing:** You only pay Meta's official rates. We don't charge per message.
- **2-Way Interactive Messages:** Support for buttons (Confirm/Cancel) with instant Webhook callbacks.
- **Built for Scale:** Handle millions of requests for E-Commerce, CRMs, and SaaS platforms.
- **No-Code Setup:** Easily connect WooCommerce, Shopify, Odoo, WHMCS, and Google Sheets.

## 🔐 Credentials
To use this node, you need a **Master API Key**.
1. Create a free account at [5MinutesAPI Dashboard](https://5minutesapi.com/dashboard)
2. Connect your Meta WhatsApp Business account.
3. Generate your Master API Key and paste it into the n8n credentials setup.

## 🛠️ Operations
- **Send WhatsApp Template:** Send a pre-approved Meta WhatsApp Template to any global number.
  - Supports dynamic variables (e.g., `{{1}}`, `{{2}}`).
  - Supports `record_id` and custom `callback_url` for real-time 2-Way button click tracking.
